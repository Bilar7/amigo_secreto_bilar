# Bilar DigitalTech — plano de validação

## Incluído nesta edição
- Paleta visual suave: verde floresta, marfim, verde névoa e dourado discreto.
- Marca da interface alterada para Bilar DigitalTech / Bilar Amigo Secreto.
- Chat renomeado para **Bilar Conversas**, com layout de altura total e adaptação a ecrãs pequenos.
- Campo para selecionar fotografia de perfil (imagem local até 3 MB).
- Texto da página inicial passa a apresentar ocasiões gerais, não apenas o Natal.

## Antes de publicar
- Integrar autenticação real e armazenamento seguro do perfil.
- Implementar mensagens em tempo real e separar rigorosamente conversas privadas e de grupo.
- Fazer com que o anonimato seja imposto no backend, não só na interface.
- Testar as regras de acesso ao sorteio com contas distintas.
- Testar em Android/iPhone, tablet e desktop.

**Nota:** fotos e dados continuam locais/demonstrativos nesta fase; não é uma versão de produção.
